# Remind 界面调研与设计提案

调研：2026-10-15。审核：2026-10-16，用户选定「同宽操作」，据此实现与验证。同目录 review.html 保留为交互设计参考，默认展示已选方案。

## 已确认的约束

- Windows、macOS 桌面轻应用，以小看板为主。
- 保留居中大倒计时和原来的分段刻度条，不再替换刻度的表现形式。
- 看板保留开始／暂停／继续提醒、重置时间；不显示“现在休息”和铃声／工作时段底栏。
- 默认工作间隔 45 分钟、休息 3 分钟，均可自定义；默认静音。
- 提前一分钟的单行提示显示 5 秒自动关闭；关闭不改变休息期限。
- 休息全屏只有巨大倒计时和必要退出操作，多显示器同步。
- 工作日期提供快捷方案，选工作日后仍可修改时间；会议暂停与权限入口保留。

## 对当前问题的判断

1. **控件权重过多。** 时间选项铺灰底、两个操作都做大块，再叠加状态徽章，让小工具像一组卡片。增加圆角和阴影不能解决层级问题。
2. **间距由窗口撑出来。** 按钮使用自动占据剩余空间，导致节奏行与操作行脱节。应先规定内容之间的间距，再决定窗口的自然高度。
3. **分组缺少一致性。** 标签、数值、箭头、按钮图标没有共同的行高与对齐方式；不同状态加入说明后还会放大问题。
4. **改动范围失控。** 用户已经认可刻度条，后续设计将它视为保留项，不再为了追求“简约”改掉。

## 推荐设计：保留主体，收敛下方控件

### 看板

- 368 逻辑像素宽；自然高度按内容决定，不留固定的提示空槽。
- 原品牌、居中大数字、分段刻度保留。
- 间隔与休息时长放在一条轻量文字行；无常驻灰色背景。数值与箭头整体可点击，焦点和悬停反馈清楚。
- 主操作用一颗深色按钮。重置保留完整文字，视觉较轻；两项拥有同样的点击高度。
- 设置仍在右上角；铃声、工作时段只在设置中出现。
- 自动暂停／权限问题只增加一行必要反馈，不把所有状态说明常驻。

设计稿提供两种操作权重供比较：**轻量操作**（重置为文字）与**同宽操作**（主按钮加浅描边次按钮，用户已选）。两版保留相同的刻度、内容与间距，便于只比较按钮处理。

### 拟定尺寸

这些是本项目设计选择，需要在 100% 比例和两平台真机上验证，并非来自竞品的像素测量。

| 项目 | 提案 |
| --- | --- |
| 内容左右边距 | 24 px |
| 正文／操作字号 | 13 px |
| 辅助状态字号 | 12 px |
| 看板数字 | 88 px，等宽数字；三位分钟自适应 |
| 时长选择行 | 32 px 点击高度 |
| 主次按钮 | 40 px 同高，按钮间 12 px |
| 刻度到时长选择 | 12 px |
| 时长选择到操作 | 24 px，固定间距 |
| 操作到底边 | 24 px |
| 设置组内／组间 | 12–16 px／24 px |

### 设置

保持一个窄窗口，不加侧栏。按时间、提醒、工作时段、会议、外观、系统与更新分组；同一组标签左齐、控件右齐。重复日期用一排快捷选项，工作时段启用后展开日期和时间。选择“工作日”只改变日期，不覆盖用户填的时间。

保存／取消固定在底部，错误贴近字段并聚焦；保存中禁止重复提交，失败保留草稿。外观可即时预览，取消恢复。辅助功能权限需提供“去开启”；打开设置不等于已经授权。

### 提醒与休息

提前提醒只有“1 分钟后休息”和关闭按钮，约 260 × 52；5 秒自动关闭，不增加倒计时条、图形或副文案。设计预览会实际演示自动关闭，但不会触发系统通知。

休息保持用户已确认的巨大倒计时，无标题、品牌、图形、说明和全屏按钮；延后／跳过为低权重文字操作。设计稿展示缩略效果，实际安装应用仍须覆盖全部显示器。

### 状态与交互检查

- 待开始、计时、手动暂停、会议暂停、缺权限、更新提示分别查看，必要说明才出现。
- 一次只打开一个时长菜单；提供预设与自定义。Esc 关闭菜单，Tab 可进入自定义输入，保存后返回触发控件。
- 不让窗口高度变化把已收起看板重新唤起，不在休息中弹出看板。
- 深浅色对比度、焦点、100%／125%／150% 缩放与窄窗口单独验收。
- 巨大计时和刻度不能因三位分钟挤出边界；状态变化不能留下一块无用空白。

## 审核顺序

用户已确认同宽操作：两颗按钮同宽同高，主按钮填色、重置轻描边；刻度条保持原形式。按此收敛看板和设置，验证完成后生成测试安装包；真实会议及完整跨平台验收边界仍见 MEETINGS.md。
