# v0.1.6 托盘、权限与响应修复

2026-10-16。v0.1.5 草稿不发布；这一版本包含其改动及以下修复。

- macOS 托盘悬浮 350ms 显示轻量操作卡；点击只切换看板，右键保留原生菜单。小卡、看板和休息窗口互斥；移动进小卡可继续操作，离开 250ms 收起，迟到的加载不能把已取消的小卡重新弹出。
- 删除同时绑定自动上下文菜单和点击看板的行为；移除托盘中的重复“现在休息”。
- Mac 会议扫描由独立进程改为主应用内的 Swift／Node-API 模块，使用同一授权身份；扫描在后台线程，不读取任何会议正文。授权标记过期时仅用允许软件的成功受保护读取确认实际访问能力。
- 签名检查异步进行，不再等待它才创建界面和注册 IPC；签名结果确定前保守使用手动更新路径。
- 去掉看板每次聚焦都同步查询登录项；短期缓存系统状态、设置返回强制刷新；已符合用户选择时不重复登记。隐藏登录启动会预热看板。
- 设置切换只调整尺寸，不重新聚焦整个窗口。鼠标返回时聚焦看板区域；键盘返回保留设置按钮焦点与可见焦点框。

验证：136 项测试通过（后台／脚本 97、前端 39），类型检查和完整构建通过。新增覆盖小卡慢加载取消、看板互斥、跨越托盘到小卡的指针行为、键盘／鼠标焦点返回和延迟签名结果。隔离开发运行记录看板 loadURL 约 52ms；这是页面加载时间，不代表安装版冷启动总耗时。Mac arm64 应用打包、完整签名验证、打包后 Electron 加载原生模块及异步扫描通过；一次无运行会议客户端的扫描约 21ms，期间主事件循环继续运行，不代表复杂会议界面的扫描耗时。发布流程也增加已打包原生模块的运行校验。

实际系统授权、真实腾讯／飞书入会，以及 Windows／Intel 真机仍按 MEETINGS.md 验收；不以本地测试代替这些结果。Mac 开发者签名／公证仍需证书。
