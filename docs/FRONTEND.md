# Remind 前端开发说明

日期：2026-10-16。交付范围：独立前端、浏览器模拟适配器及正式桌面 IPC 适配器。后台实现与验证边界见 [桌面后台说明](DESKTOP.md)。

## 1. 运行和验证

```sh
npm ci
npm run dev --workspace frontend
npm run test --workspace frontend
npm run build --workspace frontend
```

根目录工具链使用 Node.js 24 LTS（最低 22.12）。最初独立预览曾在 20.20.2 验证；接入 workspace 后统一按根目录锁文件安装。开发服务器仅监听本机；构建输出到 `frontend/dist/`，不是桌面安装包。

## 2. 视觉与界面

小看板宽 368 逻辑像素，默认高约 378，必要状态信息按内容增高。采用用户已选的同宽操作：按钮高 40px、间距 12px，时长行到按钮固定 24px，不使用剩余窗口高度撑开间隔。设置在同一个窗口内切换。窗口受工作区限制时内容内部滚动，设置的返回、保存和取消保持可见；隐藏后不会因测量重新唤起。

使用中性灰底、石墨色主按钮和少量深青绿，系统展示字体用于居中倒计时，系统正文字体用于操作。横向时间刻度表示本轮已过时间，末端青绿色刻度表示接下来的休息；删除圆形表盘、预计休息时间提示及重复说明。普通计时、手动暂停和待开始状态不额外展示解释行；自动暂停只保留会议名称、下次工作时段等必要信息。颜色、间距、圆角、阴影集中在 `styles.css`；深色模式独立调色。无在线字体和远程素材。界面支持键盘焦点、原生表单、开关语义、错误提示和系统减少动态效果偏好。

主要界面：

- 小看板：居中大倒计时、间隔／休息时长快捷菜单，以及等宽的开始／暂停／继续和重置时间按钮。删除“现在休息”按钮、顶部重复重置图标和底部铃声／工作时段栏；铃声和工作时段仅在设置中调整。R 重置，空格切换手动暂停。
- 设置：间隔／休息时长输入（预设在看板快捷菜单）、提前提醒、铃声／试听、多个工作时段、星期选择、外观。工作日期提供“工作日／每天／自定义”快捷方案，选择日期方案保留时间；关闭工作时段后收起明细，错误时重新展开并聚焦。支持午休分段，最多 12 个时段。错误贴近对应字段，保存时聚焦首个错误；保存失败保留草稿。⌘／Ctrl + Enter 保存，Esc 取消。外观选择即时预览，取消恢复原外观，保存后才持久化。
- 休息画面：中央只有超大倒计时，底部保留“延后 5 分钟”“跳过”。无图形、标题、副文案、进度条和全屏按钮。Esc 提前结束，到期自动返回；退出请求在等待时禁止重复提交。初始焦点放在休息区域，Tab 可聚焦操作。覆盖出现期间保留未保存的设置草稿。
- 提前提醒：260 × 56 的单行静音浮层“1 分钟后休息”，5 秒后自动关闭，也可手动关闭；不会取消或推迟到期休息。同一轮手动暂停后继续不重复发送。正式后台和浏览器模拟共用展示时长常量。
- 预览工具：与产品操作分开，模拟腾讯会议、工作时段、剩余时间；不读取实际系统信息。

## 3. 前后端边界

```text
frontend/src/
  contracts/reminder.ts             重导出 shared/reminder.ts 契约
  components/                      品牌、数字计时与横向刻度、开关
  features/                        看板、设置、休息、预览工具
  services/desktop-client.ts        正式 IPC 适配器与更新状态订阅
  services/mock-reminder-client.ts  浏览器模拟适配器
  services/storage.ts               浏览器本地设置存储
  domain/schedule.ts                重导出 shared/schedule.ts 纯函数
  lib/                             格式化、试听音效
  App.tsx                          视图切换和订阅
  main.tsx                         适配器注入入口
```

React 组件只调用 `ReminderClient`，不导入模拟服务，不直接访问 Electron、系统进程、文件或本地存储。`PreviewControls` 是独立的开发接口，不属于桌面正式接口。

`main.tsx` 检测受限的 `window.remind` 桥接，桌面模式注入 `DesktopClient`，浏览器模式注入 `MockReminderClient`；正式模式不传 `preview`。桌面适配器先取得完整快照，缓存最新快照并通知订阅者；`getSnapshot` 在没有新状态时必须返回相同对象，以符合 React 外部存储订阅约定。命令统一返回 Promise，设置失败返回可读错误。

正式桌面端负责唯一计时权威、会议信号、暂停原因、工作时段、持久化、铃声和窗口生命周期。模拟计时不作为正式后台核心。主进程指定唯一有播放资格的休息窗口，提前提醒和其他屏幕不播放开始铃声。

快照的 `revision` 为当前实例递增版本，桌面适配器丢弃旧版本，初始化先订阅再取完整快照，避免慢响应覆盖新状态。暂停原因用数组表示；手动暂停、会议暂停、非工作时段可以共存。锁屏、休眠及安装更新原因已扩展到共享契约；会议故障与多场会议细分状态仍待真实检测适配。

前后端分离指本地桌面服务与渲染界面分离，当前没有 HTTP 后端或云端服务。未来养成模块可消费桌面端确认的休息事件，不能依赖前端倒计时，也不向计时适配器加入宠物逻辑。

## 4. 模拟行为与已知边界

- 默认 45 分钟、休息 3 分钟、静音、提前 1 分钟提醒，工作时段限制默认关闭。
- 手动暂停冻结剩余时间；会议／时段变化重新计满间隔，同时保留手动暂停。
- 设置保存至当前浏览器来源的 localStorage；重载后不恢复旧倒计时或休息画面，保留手动暂停意图。
- 限定工作时段采用本机时间，开始包含、结束排除；临近下班时不补发无法落在当前时段内的提醒。允许时段外主动休息。
- 已开始的休息使用当轮时长，修改休息设置只影响以后。
- 合成铃声无需素材下载；浏览器可能限制自动播放。试听和用户点击后的播放可用性仍受环境影响。
- 会议自动暂停为实验性功能，正式桌面端使用腾讯／飞书专用本地适配器；真实会议组合仍待用户测试。浏览器预览仅模拟信号，见 [会议说明](MEETINGS.md)。
- 浏览器休息画面占满视口，无全屏按钮；正式桌面端在各显示器创建同步覆盖窗口。浏览器无法提供跨应用置顶或多显示器覆盖。
- 页面后台节流、关闭标签页、系统休眠会影响模拟提醒。真实系统挂起与时区变化规则由桌面端处理；此版本不能作为可靠的后台提醒工具使用。
- 桌面端已接入托盘、用户自主更新、自启动与会议权限／故障处理；独立浏览器预览不展示原生更新和系统入口。

## 5. 验证记录

自动验证：共 131 项测试通过（后台／脚本 93、前端 38）。覆盖提前提醒 5 秒自动关闭且不改变休息期限、菜单自定义输入键盘可达、错误字段聚焦、外观预览取消恢复、时段上限、隐藏时段错误展开，以及窗口内容高度与屏幕锚点。TypeScript 检查、独立前端和桌面生产构建通过。

浏览器交互验证：开始／暂停、时长修改、工作时段重叠提示及保存、模拟会议叠加、提前提醒、自动进入休息、Esc 退出、浅深色与设置持久化。新版浅深色均已检查，并在 320 像素视口确认看板没有横向溢出。具体桌面能力的验收仍按 SPEC 和技术设计进行，前端验证不等于 Windows／macOS 真机验收。
