# Remind

面向 Windows 和 macOS 的本地休息提醒应用。默认每 45 分钟以静音全屏画面提醒用户起身活动，间隔可自定义。

已完成可独立运行的前端预览。桌面系统能力与前端通过接口分离，当前由本地模拟服务驱动；尚未提供 Windows／macOS 安装包。

## 运行前端

需要 Node.js 20.19+ 或 22.12+。

```sh
cd frontend
npm ci
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。

- 小看板：开始、暂停／继续、现在休息。
- 设置：提醒间隔、休息时长、提前 1 分钟提醒、可选铃声、工作日及多个工作时段、浅深色外观。本机保存设置与手动暂停意图。
- 休息画面：倒计时、自动结束、提前结束／Esc；可主动进入浏览器全屏。
- 右下角“前端预览”：快速体验提前提醒、5 秒后休息、会议暂停、非工作时段。只注入模拟状态，不检测真实会议。

```sh
npm test
npm run build
```

前端接入说明、目录边界及验证记录见 [前端开发文档](docs/FRONTEND.md)。

浏览器预览只覆盖当前页面，依赖页面保持运行；原生托盘、多屏覆盖、系统锁屏／休眠、会议识别、开机启动和安装更新留待桌面端接入。

## 当前方向

- 托盘／菜单栏小看板，加全屏休息界面。
- 默认休息 3 分钟且可自定义，提前 1 分钟轻提醒，支持工作日与工作时段设置。
- Electron + React + TypeScript 为首选方案，先验证后台资源占用和系统能力。
- 不需要账号、云端后端或持续联网。
- 优先复用成熟库和经过核对的开源实现；不整体搬入复杂产品。
- 腾讯会议、飞书会议自动暂停是目标能力，按操作系统及软件版本验证后开放。
- 未来桌宠与养成仅预留模块边界，本期不实现玩法。

本仓库的对外许可证尚未确定；调研第三方项目不代表已引入其代码或素材。
