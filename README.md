# Remind

面向 Windows 和 macOS 的本地休息提醒应用。默认每 45 分钟静音全屏提醒，休息 3 分钟；间隔和休息时长均可自定义。

已接入 Electron 桌面后台，前端保持独立。托盘、后台计时、本地设置、工作时段、锁屏／休眠处理、多屏休息窗口、开机自启动和更新检查已实现。启动后会自动查看已发布版本，下载和安装仍由用户决定。macOS 菜单栏在图标旁显示倒计时或暂停／休息状态；Windows 把同样的信息放在托盘提示中。会议识别尚未接入；正式签名、Windows 真机验收及跨版本更新验收尚未完成。

## 运行桌面端

使用 Node.js 24 LTS（最低 22.12）。在项目根目录执行：

```sh
npm ci
npm run dev
```

首次安装会下载 Electron 运行时。桌面开发页面使用 5174 端口，可与独立前端预览同时运行。看板可以最小化，收起后后台继续计时。看板和设置里的“退出 remind”，以及托盘菜单的同一项，会停掉计时并彻底退出。

看板的重置按钮在倒计时数字右侧，托盘菜单也有同一项。它会把倒计时重新记满一个完整间隔并继续计时。休息中使用时会结束本轮休息。

点倒计时数字可以改提醒间隔：输入分钟，用方向键或滚轮增减，回车确认，Esc 取消。间隔可选 25／45／60 分钟，休息时长可选 1／3／5 分钟，也可以直接填一个数字。

“暂停提醒”可以选择 30 分钟、1 小时或直到明天，到点自动继续；也可以一直暂停。空格暂停或继续，R 重置计时，B 现在休息。休息画面可以“再给我 5 分钟”，或按 Esc“跳过这次”。底栏用开／关标出铃声和工作时段的当前状态。

开机自启动默认关闭。在设置里打开“开机自启动”后，登录时只出现在菜单栏或托盘，不自动打开看板。开关显示系统的实际结果；如果系统还没允许，开关会回到关闭并说明原因。

```sh
npm test
npm run build
npm run pack
npm run dist
```

`pack` 输出测试应用目录，`dist` 输出当前操作系统的安装包，均不上传。文件位于 `release/`。GitHub Actions 在没有 Developer ID 凭证时仍会打出 Mac 和 Windows 安装包，并为 Mac 应用做 ad-hoc 签名；推送 `vX.Y.Z` 标签后上传到 Release 草稿，需要维护者手动发布。配齐签名凭证后，同一次构建改用 Developer ID 签名（Mac 还会公证），不再使用 ad-hoc。

## 安装未签名的 Mac 包

没有 Developer ID 时，安装包带有 ad-hoc 签名。第一次打开时，macOS 会提示无法验证开发者。在访达中右键 remind.app，选择“打开”。如果仍然出现“remind.app 已损坏，无法打开”，在终端执行：

```sh
xattr -cr /Applications/remind.app
```

## 软件更新

启动约 15 秒后，以及之后每 6 小时，自动检查已发布的稳定版本。检查失败不弹错误，也不显示成“已是最新版本”。发现新版本时给出静音系统通知，并在看板和设置里标出来。不会自动下载，也不会自动安装。

Windows 使用应用内“下载更新 → 重启安装”。当前未签名的 Mac 安装包无法完成系统要求的应用内安装，发现新版本后改为打开 GitHub Releases 下载页。已用 Developer ID 签名的 Mac 包仍走应用内下载和安装。设置里始终保留“检查更新”。休息、准备休息、锁屏、休眠或会议期间不能安装。

更新来源固定为本仓库的公开 GitHub Releases；没有发布版本时不能完成实际升级。发布流程生成 Windows NSIS、Mac DMG／ZIP 和更新元数据，先生成草稿，由维护者检查后发布。签名配置及操作步骤见 [桌面后台与发布说明](docs/DESKTOP.md)。

## 独立前端预览

```sh
npm ci
npm run dev --workspace frontend
```

访问终端显示的地址（默认 http://127.0.0.1:5173）。浏览器使用模拟服务，右下角可模拟会议、提前提醒和休息；不具备原生后台或系统检测能力。桌面模式自动使用 IPC 接口，不展示模拟工具。
